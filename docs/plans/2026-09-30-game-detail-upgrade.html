Better Game Details

Act on a game without leaving its details. Read English copy, open its Steam reviews, and browse all validated source media. Keep Spanish EUR prices and every existing hidden/watch/thinking entry intact.

Baseline: 38f35ef. Planning only. Research and source evidence.

1. What Is Actually Broken

  • The modal has no hide, watch, or reconsider controls; the cards already have them.
  • Cards and details display the Spanish catalog excerpt. Nintendo's English feed returns the same ID with English copy.
  • Steam buttons already exist, but Future Knight has no stored Steam match, ratings, or media.
  • Nintendo exposes six screenshots. Steam's current Future Knight entry exposes 21 screenshots and two streaming videos. These are source counts, not a promised 27 unique images.
  • The media script omits the Nintendo page URL, skips existing incomplete entries, replaces rather than combines source assets, and truncates IGDB results.
  • Both maintenance scripts need a CLI import repair. The dialog also refocuses itself when gallery mode changes.

The authenticated production layout could not be visually checked: the browser reached the login page. Local authenticated browser tests are an implementation gate, not evidence already obtained.

2. Chosen Approach

Extend the existing components, preference endpoint, media snapshot, and manual maintenance workflow. No new database, translation service, scraper service, or Telegram behavior.

  • Price authority: Spanish Nintendo records determine prices, store links, availability, classification, and eligibility. English exact-ID records supply presentation copy only.
  • Language: official English descriptions first; if unavailable, retain the Spanish Nintendo excerpt (user-approved fallback). Reuse English category labels and format dates in English. Proper names and third-party page/video language are not translated.
  • Steam: validated game identity is separate from review evidence. Keep existing rating types and eligibility unchanged; add optional Steam match metadata to media entries.
  • Media: Nintendo + matched IGDB + matched Steam; union and deduplicate with provenance. Label Steam screenshots/video as PC footage. Collect source pages within bounded pagination; explicitly report incomplete collection.
  • Playback: screenshot gallery, selectable trailers, native video where supported, validated YouTube embeds. Steam HLS requires native Safari playback or a lazily loaded hls.js player for Chromium. Add only this focused dependency if required by fixture-backed playback tests; no gallery/UI library.
  • Operations: reuse manual maintenance with an explicit target and dry-run default. No enrichment acquisition on the Telegram delivery critical path. No production backfill under planning approval.
